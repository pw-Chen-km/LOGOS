# LOGOS 2.0 Fixtures

This directory contains small, synthetic fixtures that are safe to commit.
They show the expected shape of LOGOS inputs and generated paper skill packs
without including local run traces, downloaded papers, API responses, or a full
generated `paper_skills/` directory.

Use these fixtures for documentation, smoke tests, and examples. Runtime output
from real runs should stay in ignored directories such as `runs/`, `artifacts/`,
`paper_skills/`, and `paper_library/`.
